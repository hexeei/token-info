# Token Research Checklist

Интерактивный дашборд для системного разбора крипто-токенов перед добавлением в
портфель. Вводите тикер — часть полей подтягивается автоматически из публичных API,
остальное заполняете и скорите вручную. На выходе — агрегированный скор, вердикт и
автоматически найденные ред-флаги.

## Стек

- **React + Vite**
- **TailwindCSS** (тёмная тема «Violet Quant», палитра через CSS-переменные)
- **Recharts** — radar-чарт скоров и bar-таймлайн анлоков
- **LocalStorage** — сохранённые разборы (без своего бэкенда)
- Прямые `fetch` к публичным API — ключи не требуются

## Источники данных (auto-fill)

При выборе токена автоматически подтягивается:

- **CoinGecko** (`/search`, `/coins/{id}`) — название, лого, цена, market cap, FDV,
  supply (circulating / total / max), ATH и % от ATH, 7d/30d тренд, сектор (из
  категорий), ссылки (сайт, доки, X).
- **DefiLlama** (`/protocols`, `/summary/fees/{slug}`) — TVL, fees и revenue, если
  протокол удаётся смэтчить по символу/названию.

Все автозаполненные поля помечаются бейджем **auto** и остаются редактируемыми.
Ошибки и лимиты API обрабатываются мягко: если запрос не прошёл, поле просто
остаётся пустым для ручного ввода — приложение не падает.

> Примечание: CoinGecko free-tier лимитирован по частоте запросов; при 429 поля
> заполняются вручную.

## Блоки чеклиста

1. **Идентификация** — тикер, название, лого, сеть, контракт, ссылки (без скора).
2. **Сектор и нарратив** — сектор (предзаполнен из CoinGecko) + сила нарратива.
3. **Токеномика** — supply и % в обращении, FDV/MC коэффициент, распределение с
   валидацией суммы = 100%, таймлайн анлоков (bar-чарт) и детектор ред-флага
   (анлок > 10% от circ supply в ближайшие 90 дней).
4. **Команда и бэкеры**.
5. **Продукт и трэкшн** — TVL / revenue / fees (auto из DefiLlama), ≈P/S.
6. **Ликвидность и рынок** — объём, Vol/MC, позиция к ATH, тренды.
7. **Риски** — авто-собранные ред-флаги + ручная оценка (выше скор = ниже риск).
8. **Оценка и апсайд** — целевой мультипликатор → целевая цена / MC.

Каждый скорящийся блок: поля + слайдер скора 0–10 + заметка. Итоговый скор —
взвешенное среднее по блокам (веса в `src/lib/scoring.js`), приведённое к 0–100.
Критичный ред-флаг ограничивает вердикт сверху.

## Запуск

```bash
npm install
npm run dev      # дев-сервер
npm run build    # прод-сборка в dist/
npm run preview  # предпросмотр сборки
```

## Структура

```
src/
  api/         CoinGecko и DefiLlama клиенты (fail-soft)
  lib/         scoring (модель, ред-флаги, вердикт), format, sectors, storage
  components/  UI-примитивы, поиск, блоки чеклиста, чарты, summary
  App.jsx      состояние, auto-fill, сохранение/загрузка
```

Не финансовый совет — инструмент для собственного due diligence.

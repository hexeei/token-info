# Token Research Checklist

Интерактивный дашборд для системного разбора крипто-токенов перед добавлением в
портфель. Вводите тикер — часть полей подтягивается автоматически из публичных API,
остальное заполняете и скорите вручную. На выходе — агрегированный скор по шкале
0–10, автовердикт и список ред-флагов.

## Стек

- **React + Vite + TypeScript**
- **TailwindCSS** (тёмная тема «Violet Quant», палитра через CSS-переменные)
- **Recharts** — radar-чарт скоров, bar-таймлайн анлоков, сгруппированный radar для сравнения
- **LocalStorage** — автосохранение разборов (без своего бэкенда)
- Прямые `fetch` к публичным API — ключи не требуются

## Источники данных (auto-fill)

- **CoinGecko** (`/search`, `/coins/{id}`, `/coins/markets`) — название, лого, цена,
  market cap, FDV, supply (circulating / total / max), ATH и % от ATH, 7d/30d тренд,
  сектор (из категорий), ссылки; MC/FDV конкурентов по тикеру для блока апсайда.
- **DefiLlama** (`/protocols`, `/summary/fees/{slug}`) — fees и revenue, если протокол
  удаётся смэтчить по символу/названию.

Автозаполненные поля помечаются бейджем **auto** и остаются редактируемыми.
Ошибки/лимиты API обрабатываются мягко: при неудачном запросе поле остаётся пустым
для ручного ввода — приложение не падает.

## Блоки чеклиста

1. **Идентификация** — тикер, название, лого, сеть, контракт, ссылки (без скора).
2. **Сектор и нарратив** — сектор (auto из CoinGecko) + сила нарратива.
3. **Токеномика** — supply и % в обращении, FDV/MC, распределение с валидацией
   суммы = 100%, таймлайн анлоков (bar-чарт) + детектор ред-флага (анлок > 10% circ
   в ближайшие 90 дней).
4. **Value accrual** — revenue model, fees/revenue (auto), чекбоксы механик
   (governance / staking / fee share / real yield / ничего) + флаг слабого value
   accrual, если только governance или ничего.
5. **Байбек и сжигание** — есть ли байбек, размер/периодичность/% выручки, burn,
   авто-расчёт buyback yield = годовой байбек ÷ market cap.
6. **Тренд** — аптренд/даунтренд/рейндж (дефолт предлагается по 7d/30d), % от ATH,
   momentum.
7. **Апсайд** — целевая MC / X-потенциал, comps конкурентов (MC/FDV, авто-подтяжка
   по тикеру) с авто-расчётом X до каждого конкурента.

Каждый скорящийся блок: поля + слайдер 0–10 + заметка.

## Итог и вердикт

- Radar по 6 скорируемым блокам (фиолетовый).
- Взвешенный общий скор 0–10; веса в `src/config.ts` (`WEIGHTS`) — токеномика и
  value accrual тяжелее.
- Автовердикт по порогам (`VERDICT_THRESHOLDS`): > 7.5 — сильный кандидат (зелёный),
  5–7.5 — средний (фиолетовый), < 5 — пас (красный).
- Список всех ред-флагов из блоков 3 (токеномика) и 4 (value accrual).
- Экспорт разбора в **JSON** и **Markdown**.

## Главный экран

- Кнопка «Новый разбор».
- Сохранённые разборы карточками: лого, тикер, общий скор, вердикт, дата.
- Сравнение: выбрать 2–3 разбора → сгруппированный radar + таблица скоров.
- Клик по карточке открывает разбор на редактирование.

## Запуск

```bash
npm install
npm run dev        # дев-сервер
npm run build      # прод-сборка в dist/
npm run preview    # предпросмотр сборки
npm run typecheck  # проверка типов (tsc --noEmit)
```

## Структура

```
src/
  types.ts       схема данных разбора (identity, sector, tokenomics с анлоками,
                 valueAccrual, buyback, trend, upside, scores, notes, meta)
  config.ts      веса, пороги вердикта, сектора, механики, фабрика пустого разбора
  api/           coingecko.ts, defillama.ts — API-слой (fail-soft)
  lib/           scoring, format, sectors, storage, export (JSON/Markdown)
  components/    Dashboard, Editor, Summary, CompareView, TokenSearch, ui,
                 blocks/*, charts/*
  App.tsx        состояние, автосохранение, auto-fill, роутинг список ↔ редактор
```

Не финансовый совет — инструмент для собственного due diligence.
